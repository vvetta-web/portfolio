# Портфолио — одностраничные сайты

![Портфолио](00-portfolio.jpg)

Демо-сайты для малого бизнеса: собраны на готовом движке (скролл-сцены, адаптив под телефон), опубликованы на GitHub Pages. Демо закрыты от поисковиков.

## Работы

### 1. Кофейня «Кофе & Бетон»

![Кофейня «Кофе & Бетон»](01-coffee.jpg) — [открыть сайт](https://vvetta-web.github.io/)

Сайт кофейни в стиле брутализм: крупная антиква в макете страницы, спокойная кремовая подложка и один акцентный красный цвет. Главный экран — провокационный слоган «Пей меньше. Чувствуй больше.», дальше — меню с ценами, афиша и контакты. Минимум иллюстраций, максимум типографики.

### 2. RAYA — магазин солнцезащитных очков

![RAYA](02-ochki.jpg) — [открыть сайт](https://vvetta-web.github.io/raya/)

Бренд-лэндинг российского бренда очков: тёплая фотография на весь первый экран, слоган «Солнце — не повод щуриться», прямая кнопка «Выбрать на Wildberries». Дальше — модели, преимущества, статьи и контакты. Сайт ведёт не в корзину, а в маркетплейс.

### 3. Сайт бригады строителей

![Сайт бригады строителей](03-stroiteli.jpg) — [открыть сайт](https://vvetta-web.github.io/portfolio-stroiteli/)

Одностраничный сайт для бригады, которая строит каркасные дома и бани. Главный оффер — прозрачность: договор и смета до первого платежа, каждый этап принимает сам заказчик, оплата — только после приёмки. Показывают живую стройку, а не рендеры, на сайте — калькулятор сметы и примеры работ.

### 4. Ремонт квартир

![Ремонт квартир](04-remont.jpg) — [открыть сайт](https://vvetta-web.github.io/portfolio-remont/)

Сайт ремонтной бригады с главным обещанием — «смета не растёт после подписания». Работа по графику: план на неделях, фотоотчёт каждые 7 дней, оплата по этапам после приёмки. В основе первого экрана — фото реальной квартиры до ремонта, есть форма расчёта стоимости.

### 5. Сайт мебельной мастерской

![Сайт мебельной мастерской](05-mebel.jpg) — [открыть сайт](https://vvetta-web.github.io/portfolio-mebel/)

Тёмный, «вечерний» лендинг мастерской, которая делает кухни и шкафы под размеры конкретной квартиры. По плану из ЖК или фото стены с рулеткой за день дают предварительный расчёт, точная смета — после замера с образцами фасадов. Гарантия 24 месяца.
